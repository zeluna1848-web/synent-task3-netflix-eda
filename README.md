# Netflix Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project is part of my **SYNET Internship Program**. The objective of this project is to perform **Exploratory Data Analysis (EDA)** on the Netflix dataset to understand content trends, distribution, and patterns available on the platform.

The analysis focuses on cleaning the dataset, exploring important features, and creating visualizations to gain meaningful insights about Netflix movies and TV shows.

---

## 🎯 Objectives

- Understand the structure and characteristics of the Netflix dataset
- Perform data cleaning and preprocessing
- Handle missing values and duplicate records
- Analyze Netflix content distribution
- Identify trends in movies and TV shows
- Visualize important patterns using Python libraries

---

## 📂 Dataset

**Dataset Name:** Netflix Movies and TV Shows Dataset

The dataset contains information about Netflix titles including:

- Show ID
- Type (Movie / TV Show)
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre
- Description

## 🔄 Project Workflow

### 1. Data Loading
- Imported the Netflix dataset using Pandas.
- Checked the dataset structure and dimensions.

### 2. Data Exploration
Performed initial analysis:
- Displayed sample records
- Checked column names
- Examined data types
- Analyzed dataset statistics

### 3. Data Cleaning

The following preprocessing steps were performed:

- Removed duplicate records
- Handled missing values
- Converted date columns into proper format
- Cleaned inconsistent data entries

### 4. Exploratory Data Analysis

Analyzed different aspects of Netflix content:

- Movies vs TV Shows distribution
- Content released over years
- Top countries producing Netflix content
- Popular genres
- Ratings distribution
- Content duration analysis

## 📈 Key Insights

- Netflix contains a larger number of movies compared to TV shows.
- Content production has increased significantly over recent years.
- The United States contributes the highest number of Netflix titles.
- Drama and International content are among the most common genres.
- Netflix offers content across different ratings and categories.
