# 🎬 Netflix Exploratory Data Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python. The goal is to clean the dataset, analyse trends, create visualisations, and derive meaningful insights about Netflix's content library.

---

## 🎯 Objectives

- Load and explore the Netflix dataset
- Clean missing and inconsistent data
- Remove duplicate records
- Analyse Netflix content trends
- Create informative visualisations
- Generate business insights

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS Code

---

## 📈 Key Insights

- Netflix has more Movies than TV Shows.
- TV-MA is the most common content rating.
- The United States contributes the largest amount of Netflix content.
- Netflix's content library expanded rapidly in recent years.
- Drama and International Movies are among the most common genres.

## 🚀 How to Run

1. Clone this repository.
2. Install the required libraries:

```bash

```

3. Open:

```
notebooks/netflix_eda.ipynb
```

4. Run all notebook cells.
